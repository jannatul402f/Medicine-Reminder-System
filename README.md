💊 Medicine Reminder \& Health Tracker



Project Overview



Medicine Reminder \& Health Tracker is a web-based application that helps users manage medicines, dosage schedules, reminders, and medication history.



Features



\* User Registration and Login

\* Medicine Profile Management

\* Dosage Schedule

\* Medicine Reminders

\* Missed Dose Tracking

\* Medicine Stock Management

\* Refill Reminders

\* Medication History

\* Prescription Storage

\* Symptom Logging

\* Adherence Analytics

\* Notification System



Technologies Used



\* HTML

\* CSS

\* JavaScript

\* Node.js

\* Express.js

\* SQLite



Installation



1\. Clone the repository.

2\. Open the project folder.

3\. Run npm install.

4\. Run node server.js.

5\. Visit http://localhost:3000.
